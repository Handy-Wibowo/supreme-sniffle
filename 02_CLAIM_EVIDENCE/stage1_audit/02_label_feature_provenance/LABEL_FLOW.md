### E-label naming warning

Here E1–E8 denote local numbered `Experiment` directories. v8 package names its three included notebooks `Exp6/7/8` for transfer/threshold/error taxonomy. `phishing/ARBITRATION.md:33-43` has a different E1–E11 evidence inventory; those labels are not the workspace Experiment numbers.

## Positive-class and confusion contract

Current contract: `y=0` benign; `y=1` phishing; probability is `P(phishing)` selected by model `classes_` value 1; `pred=1` at threshold 0.5 is phishing. `confusion_matrix(labels=[0,1])` flattens to TN, FP, FN, TP. Thus `FPR_benign=FP/(FP+TN)` and `miss_phish=FN/(FN+TP)` (`Experiment/5 - PhiUSIIL Focused Ablation/src/evaluate.py:28-89`; `src/run_experiment.py:85-98,107-143`).

Legacy E3 supplied source labels with 0=phish and 1=benign. Its first confusion class was phish, not TN; default sklearn metrics use `pos_label=1`, hence target benign. The E3 `fpr=FP/(FP+TN)` equals the phishing miss rate under that matrix layout. Never transfer E3 metric names to current phishing-positive manuscript numbers without recomputation.

## A2 contract and source schema comparison

A2 `FEATURE_ORDER` is 18 fields, asserted unique/count=18, extracted by deterministic URL parsing, string counts/ratios, bundled PSL and IP parsing (`Experiment/5 - PhiUSIIL Focused Ablation/src/features.py:30-54,57-67,80-121`). E6 asserts `Xtr.columns == Xref.columns == Xt.columns == FEATURE_ORDER` and maps target label strings before scoring (`transfer.executed.ipynb:55-65`). A2 is shared implementation identity; feature value equivalence is not implied. The 20k-row agreement report shows exact agreement 0 for `NoOfLettersInURL`, `LetterRatioInURL`, `NoOfOtherSpecialCharsInURL`, `SpacialCharRatioInURL`; `DomainLength` .06555 (`outputs/audit/audit_20261024T214912326638Z/a2_vs_source_agreement.csv:2-19`).

## Current manuscript terminology and ceiling interpretation

Current v8 DOCX uses explicit phishing-positive metrics at §2.6 (`01_Draft/BITS_Draft_Phishing_URL_Leakage_v8_final.docx:125-131`); defines A0=47, A1=41, A2=18 and says A2 is not a one-factor ablation at §2.4 (`:105-117`); reports AUC values and says they do not prove label derivation (§3.1 `:153-161`); presents paired A1−A0 group ablation and A2 representation contrast separately (§3.4 `:200-221`). It separates temporal refit from transfer and does not identify a temporal cause (§3.6–3.7 `:244-267`).

The claim that high-AUC fields are “indicating a corpus-level ceiling effect” remains a descriptive interpretation. What is verified: high full-dataset separability, near-ceiling observed in-corpus F1, and small A1−A0 conditional group effects. What is not established: the producer’s access to labels/test rows, causal role of any feature, or that ceiling was caused by these features rather than population/collection characteristics. A2 versus A0 changes source and definitions as well as feature set, so it cannot explain the ceiling by itself.
